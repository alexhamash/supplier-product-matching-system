# Supplier Product Matching System - MVP User Stories

## Main Product Catalog
- **US 1**: As a store manager, I want to view a central list of my store's internal products, so that I can see what items need supplier matches.
- **US 2**: As a store manager, I want to add new products to my main catalog with a name, SKU, brand, and category, so that they can be linked to supplier products.

## Supplier Management
- **US 3**: As a store manager, I want to create a profile for each supplier, so that I can organize product catalogs by their source.
- **US 4**: As a store manager, I want to view a list of all current suppliers, so that I can quickly access their specific data.

## Catalog Import
- **US 5**: As a store manager, I want to import a supplier's product list via a Google Sheets or Excel link, so that I don't have to manually enter every item.
- **US 6**: As a store manager, I want to see the progress or result of an import, so that I know if the supplier's products were successfully added to the system.

## Supplier Product Display
- **US 7**: As a store employee, I want to browse products imported from a specific supplier, so that I can understand what they are offering.
- **US 8**: As a store employee, I want to filter supplier products by "unmatched," so that I can focus on items that still need to be linked to a main product.

## Product Matching
- **US 9**: As a store employee, I want to manually search for a main product and link it to a supplier product, so that I can ensure 100% accuracy for complex items.
- **US 10**: As a store employee, I want to see automated suggestions for matches based on SKU similarity, so that I can quickly link products that share the same identifier.
- **US 11**: As a store employee, I want to see automated suggestions for matches based on product name similarity, so that I can efficiently link products with slightly different naming conventions.
- **US 12**: As a store employee, I want to confirm or reject an automated match suggestion, so that I maintain control over the data accuracy.

## Data Visualization & Progress
- **US 13**: As a store manager, I want to see how many supplier products are linked to each main product, so that I can identify which items have multiple sourcing options.
- **US 14**: As a store manager, I want to see an overview of matching progress for a specific supplier, so that I know how much work is left for their catalog.
